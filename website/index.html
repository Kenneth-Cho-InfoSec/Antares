AVAILABLE IN ANDROID

What the package includes

  • ARM64 production release
  • Native HTML, CSS and JavaScript rendering
  • WebGL where the renderer supports it
  • Host-integrated text and search input
NOT IN THE ANDROID PACKAGE

What to plan around

  • WebGPU and WebXR are disabled
  • Compatibility is not at WebView parity
  • Media, WebRTC, DRM, CAPTCHA and downloads vary
  • Site isolation and permissions depend on host and Android

If you depend on a site for work, sign-in or media, check it with Android WebView too. Solipsism can switch cores without replacing the browser app.

Install both pieces

Engine first.
Then choose.

Antares is not a standalone browser. Pair its companion APK with a compatible Solipsism release.

  1. 01

    Install Solipsism 9.4.0

    The current Antares 0.5.0 release notes specify Solipsism 9.4.0 as the matching host.

    ↗
  2. 02

    Get Antares 0.5.0

    Download the ARM64 companion APK from the official Antares release on an Android 13+ device.

    ↗
  3. !

    Updating from Antares 0.4.0?

    The 0.5.0 companion uses a different signing certificate. Android cannot update across those certificates: switch Solipsism back to WebView, uninstall the old Antares package, then install 0.5.0.

    ↗
  4. 03

    Choose Antares in Solipsism

    Open the core chooser or Debug Settings and select Antares. The host checks the companion package before binding.

    ✓
  5. 04

    Switch back whenever you need

    Choose Android WebView in Solipsism for pages that do not behave as expected in the experimental core.

    ↺

Three different integration paths

Choose the engine for the job.

These projects all render web content on Android, but they differ in how an app gets and embeds the engine.

Approach How it is delivered Best fit Trade-off
A Antares Servo-derived engine companion, selected inside Solipsism Solipsism users testing a second rendering core Experimental; Android 13+ ARM64; feature compatibility varies
Android WebView Android-provided web component Apps that want platform web content through the system component; Solipsism’s stable fallback Engine version and behaviour follow the Android system WebView
GeckoView Gecko engine library embedded by an Android app App teams choosing Mozilla’s embeddable engine and APIs The app integrates the library and owns its browser experience

Build, test, inspect

For engine developers.

The Android package is built from a large Rust engine tree. A desktop build is useful for engine work but is not the Android companion APK.

ANDROID ARM64 RELEASE 
./mach build --android --profile production-stripped --no-package
./mach package --android --profile production-stripped

Requires Rust, uv, Android SDK and NDK. Set ANDROID_SDK_ROOT and ANDROID_NDK_ROOT first.
